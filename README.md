# atividade-python
## Sobre a atividade

Esta atividade foi desenvolvida para praticar conceitos básicos de programação utilizando a linguagem Python.

Foram criados quatro programas diferentes, cada um trabalhando conceitos fundamentais como entrada de dados, cálculos, condições, listas e pesquisa de informações.

## Programas

### 1. Calculadora

Arquivo: calculadora.py

Este programa funciona como uma calculadora simples.

O usuário informa dois números e escolhe uma operação:

- Soma
- Subtração
- Multiplicação
- Divisão

O programa calcula e mostra o resultado da operação escolhida.

### 2. Verificação de Número

Arquivo: verificacao_numero.py

Este programa recebe um número informado pelo usuário e verifica:

- Se o número é positivo;
- Se o número é negativo;
- Se o número é zero;
- Se o número é par ou ímpar.

Neste programa são utilizadas estruturas condicionais if, elif e else.

### 3. Média do Aluno

Arquivo: media_aluno.py

Este programa recebe três notas de um aluno, calcula a média e informa a situação do aluno.

Os resultados possíveis são:

- Aprovado: média maior ou igual a 7;
- Recuperação: média entre 5 e 6,9;
- Reprovado: média menor que 5.

### 4. Lista de Nomes

Arquivo: lista_nomes.py

Este programa permite cadastrar cinco nomes em uma lista.

Depois do cadastro, o programa:

- Exibe todos os nomes;
- Informa a quantidade de nomes cadastrados;
- Permite pesquisar se um determinado nome está na lista.

## Como executar os programas

Para executar os programas, é necessário ter o Python instalado no computador.

Abra o terminal ou o ambiente de programação e execute o arquivo desejado.

Exemplo:

```bash
python calculadora.py
